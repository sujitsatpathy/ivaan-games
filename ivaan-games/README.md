# Ivann Games

Welcome to Ivann Games! This project is designed to provide fun and educational activities for children, focusing on various subjects to enhance their learning experience. Below is an overview of the activities included in this project.

## Activities

1. **Multiplication Practice**
   - Location: [multiplication/index.html](multiplication/index.html)
   - Description: Practice multiplication tables with interactive questions to improve your math skills.

2. **Addition Practice**
   - Location: [addition/index.html](addition/index.html)
   - Description: Engage in fun addition exercises to strengthen your addition skills.

3. **Country Capitals Quiz**
   - Location: [capitals/index.html](capitals/index.html)
   - Description: Test your knowledge of world capitals with a multiple-choice quiz.

4. **Country Flags Quiz**
   - Location: [flags/index.html](flags/index.html)
   - Description: Identify flags from different countries and learn about their significance.

5. **Verbal Reasoning Activities**
   - Location: [reasoning/verbal/index.html](reasoning/verbal/index.html)
   - Description: Enhance your language and comprehension skills through engaging verbal reasoning exercises.

6. **Non-Verbal Reasoning Activities**
   - Location: [reasoning/non-verbal/index.html](reasoning/non-verbal/index.html)
   - Description: Develop logical thinking and problem-solving skills with non-verbal reasoning challenges.

## Getting Started

To get started, simply open the `index.html` file in your web browser. From there, you can navigate to any of the activities listed above. Enjoy learning and have fun!
